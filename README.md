# Potsdam Sustainability Dashboard  
### Real‑Time Environmental Monitoring (Google Colab + Dash)

This project is a lightweight real‑time Sustainability Dashboard built in Google Colab using Python, Pandas, NumPy, Plotly, and Dash. It retrieves hourly weather data from the Open‑Meteo API, computes a Sustainability Index (SI), and displays interactive charts inside a Dash web app.

##  Features and Visuals
- Real‑time weather data  
- Sustainability Index (SI)  
- KPI contribution pie chart  
- Gauge indicator  
- Line charts (temperature, humidity, wind, rain)  
- Bar charts (UV index, cloud cover, pressure)  
- Dark‑theme responsive layout  
- Fully runnable in Google Colab using `jupyter_mode="external"` and there is another mode `jupyter_mode="inline"` under # if you want to see results in google colab
  

##  Why No Authentication/Login?
Authentication was intentionally not included because:
- The dashboard uses public, non‑sensitive data  
- Google Colab already runs in a private user session  
- The project’s goal is real‑time visualization, not user‑specific access  
- Adding login would increase complexity without improving functionality
